# Tela Purple Tahoe Apps

This child icon theme inherits the installed `Tela-purple` theme and overrides application icons and folder variants with artwork from `MacTahoe-nord`. Run `~/.local/bin/kde-tela-purple-accent-folders.sh` after changing KDE's accent color.

The upstream MacTahoe-nord artwork is distributed under GPL-3.0; its license is included in `COPYING`. The base Tela-purple theme remains a package dependency and is not duplicated here.
